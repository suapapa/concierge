Concierge

Temporary file hosting with TTL, public download links, and optional Google sign-in when the database is enabled.

API

Versioned REST handlers live under /api/v1 (for example GET /api/v1/health).

Upload, delete, and listing require auth (session cookie, user API key, or legacy bearer token). Public downloads use the luggage key URL from your deployment.

API explorer

With the server not in release mode (-r omitted), Swagger UI is at /swagger/index.html (shortcut /docs).

Release builds omit Swagger routes.

Full dashboard

You are seeing this page because fe/dist/index.html was not found when the server started. To serve the React app at /, run cd fe && npm install && npm run build and restart Concierge (or use the Docker image, which includes the bundle).

For local UI development with hot reload:

  • cd fe && npm run dev — Vite (default http://localhost:5173) proxies /api to this server.

When using Vite on another origin, set CONCIERGE_POST_LOGIN_REDIRECT to that URL for OAuth (see README).
